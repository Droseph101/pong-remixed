# Pong Remixed

A Pong game for Mac and Windows.

## Downloads
- [Windows 1.1.1 — installer and portable ZIP](https://github.com/Droseph101/pong-remixed/releases/tag/v1.1.1)
- [Mac 1.1 — Apple silicon](https://github.com/Droseph101/pong-remixed/releases/tag/v1.1.0)

Choose the game downloads under Assets, not the automatically generated source archives. System requirements, installation details, and security notes are on each release page.

Online play requires matching game versions; Windows 1.1.1 cannot join Mac 1.1 games.

This repository hosts game releases and update feeds. The game source code is not published here.
