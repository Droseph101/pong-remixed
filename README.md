# Pong Remixed

A Pong game for Mac and Windows.

## Download

[Download Pong Remixed 1.1.2 for Mac and Windows](https://github.com/Droseph101/pong-remixed/releases/tag/v1.1.2)

Choose the Mac ZIP, Windows installer, or Windows portable ZIP under Assets, not the automatically generated source archives. System requirements, installation details, and security notes are on the release page.

Online play requires matching versions. Both players should update to 1.1.2.

This repository hosts game releases and update feeds. The game source code is not published here.
